# 🎁 幸运抽奖转转转

一个专为QQ群、QQ频道设计的在线抽奖工具，支持转盘抽奖、管理员配置、中奖记录查询等功能。

## ✨ 功能特性

- 🎰 **转盘抽奖** - 10格转盘，实物奖品与谢谢参与交错排列
- 📱 **手机号验证** - 输入手机号参与，用于领奖验证
- ⏰ **每周限制** - 同一手机号每周只能参与一次
- 🔐 **管理员功能** - 密码保护（默认：3632），可增删改奖品
- 📊 **中奖记录** - 完整记录查询，支持筛选统计
- 💾 **数据持久化** - 使用 localStorage 保存数据

## 🎁 默认奖品配置

| 奖品 | 初始数量 |
|------|----------|

| 棉花糖 | 10颗 |

## 🚀 部署方式

### GitHub Pages（推荐）

1. Fork 或克隆本仓库
2. 进入仓库 Settings → Pages
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main`，文件夹选择 `/(root)`
5. 保存后等待1-2分钟，访问 `https://你的用户名.github.io/仓库名/`

### 其他方式

- **QQ群文件** - 直接上传 `index.html` 到群文件
- **静态托管** - 支持 Netlify、Vercel、腾讯云COS 等

## 📱 使用说明

### 参与抽奖
1. 打开抽奖页面
2. 输入11位手机号
3. 点击"立即抽奖"按钮
4. 转盘旋转后显示结果

### 管理员操作
1. 点击"管理员"标签
2. 输入密码：**3632**
3. 登录后可：
   - 添加/编辑/删除奖品
   - 清空抽奖记录
   - 重置所有数据

## ⚠️ 注意事项

- 数据存储在浏览器 localStorage 中
- 不同浏览器/设备数据不互通
- 如需数据同步，建议部署到服务器并添加后端数据库
